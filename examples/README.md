# Примеры без фиктивных хешей

Используй реальный путь к установленному скиллу. В примерах `SKILL` и `WORKSPACE` — переменные оболочки, которые пользователь/родитель задаёт существующими абсолютными путями. Не подставляй путь хоста, которого не видно в текущем terminal backend.

## Полностью автономный пример

```bash
python3 -B "$SKILL/scripts/stage_cli.py" demo --workspace "$WORKSPACE"
```

Создаётся новая папка `bounded-stage-demo-...` внутри workspace, синтетический JSON, валидный plan.json с настоящим SHA-256 и run. Контроллер делает две последовательные копии с проверками, без Hermes LLM и без TypeSafe. Ожидаемый status — `ready_for_parent_review`, `jev_calls: 0`, `generations: 0`. Это проверка механизма, не качества сметы.

## Пример с настоящим исполнителем Hermes, без TypeSafe

```bash
python3 -B "$SKILL/scripts/stage_cli.py" demo --workspace "$WORKSPACE" --generation
```

Команда возвращает `awaiting_generation` и exit 10. Передай указанный run одному native worker по `templates/worker-context.md`. Он прочитает пакет, добавит короткое поле note в JSON, не меняя operation/name/quantity/unit, запишет результат в выданный inbox-путь и вызовет submit.

Контроллер сверит исходные поля и продолжит второй шаг без перепланирования у родителя. Успешный итог — два completed, один запрос генерации и ноль запросов Jev. То, сколько внутренних обращений к своей модели сделал native worker, контроллер не знает.

Автономные unit tests обслуживают такой же запрос заранее заданным искусственным ответом. Это отдельно обозначено в тестах и не выдаётся за фактический прогон модели.

## Проверка реального API на синтетическом тексте

Только после локальной настройки ключа и явного разрешения внешнего обращения:

```bash
python3 -B "$SKILL/scripts/stage_cli.py" smoke --allow-typesafe
```

Отправляется одна короткая искусственная русская фраза без клиентских данных. Вывод показывает реальный ответ, model и usage. `calibrated: false` остаётся false: один успешный smoke не доказывает качество на сметах. Без флага или ключа команда не объявляет подключение успешным.

Ключ не вставляется в аргументы команды, карточку, сообщения Telegram или пакет worker. Устанавливай его только штатным локальным способом Hermes. Не выводи `.env` или auth.json для диагностики.

## Рабочая карточка

Родитель создаёт карточку по references/contract.md на основе текущей задачи и установленного профильного скилла. Запуск:

```bash
python3 -B "$SKILL/scripts/stage_cli.py" validate --plan "$PLAN"
python3 -B "$SKILL/scripts/stage_cli.py" init --plan "$PLAN" --run "$NEW_RUN"
python3 -B "$SKILL/scripts/stage_cli.py" advance --run "$NEW_RUN"
```

Для зарегистрированных команд добавь один и тот же `--catalog "$CATALOG"` к validate/init. Для разрешённых TypeSafe-проверок добавь `--allow-typesafe` только к init. Не добавляй этот флаг из предположения, что «пользователь установил скилл, значит любые клиентские данные можно отправлять».

`NEW_RUN` должен ещё не существовать; его родительский workspace должен существовать. Состояние не хранится внутри установленного скилла. Исходники не перезаписываются.

## Типичные остановки

`typesafe_not_authorized` — нет разрешения на внешний контекст, не обходить.

`jev_unavailable` — нет ключа/доступа, API недоступен или его ответ не соответствует контракту; успешной смысловой проверки нет.

`uncertain_choice` / `no_admissible_action` — вернуть факты планировщику, а не уменьшать пороги автоматически.

`input_changed:*` / `output_changed:*` — восстановить фактическое состояние и сформировать новый этап.

`command_timeout` / `interrupted_execution` — сначала проверить последствия. Не повторять действие вслепую.

`check_failed:*` / `semantic_check_failed:*` — основной результат не принят. Изменять или отключать проверку ради успешного отчёта запрещено.

`jev_budget_exhausted` — партий пар больше, чем оставшихся вызовов. Увеличивать бюджет можно только новой карточкой; не уменьшать `batch_size` ради «пролезть».

`unsupported_candidate_version` / `invalid_deterministic_flags` / `missing_deterministic_flag` / `too_many_candidate_pairs` — входной артефакт v2 не соответствует закрытой форме. Исправляет производитель артефакта, а не контроллер и не Jev.
